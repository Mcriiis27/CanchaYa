CanchaYa

Plataforma web para la reserva de canchas deportivas, desarrollada como proyecto académico. Permite a los usuarios consultar disponibilidad y reservar canchas, y cuenta con un panel administrativo para la gestión del sistema.

Tecnologías utilizadas
HTML, CSS, JavaScript
PHP (PDO)
MySQL
Funcionalidades
Interfaz de cliente para consulta y reserva de canchas
Autenticación de usuarios
Panel administrativo para la gestión de reservas y canchas
Manejo de horarios con corrección de errores de zona horaria
Instalación y ejecución local
Clona el repositorio:
   git clone https://github.com/Mcriiis27/CanchaYa.git
Coloca el proyecto en la carpeta de tu servidor local (por ejemplo, htdocs si usas XAMPP).
Crea una base de datos en MySQL e importa el archivo .sql incluido en el repositorio.
Configura las credenciales de conexión a la base de datos en el archivo de conexión PHP correspondiente.
Inicia Apache y MySQL desde tu panel de control local (XAMPP/WAMP).
Abre el proyecto en el navegador desde http://localhost/CanchaYa.
